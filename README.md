# マンション管理 修繕費計算システム

マンションの修繕積立金と大規模修繕のための不足金を計算するWebアプリケーションです。

## 機能

- **現在の積立金残高の管理**
- **月々の積立金額の計算**（戸数対応）
- **年間小規模修繕費用の管理**
- **大規模修繕予定費用の入力**
- **大規模修繕までの期間設定**
- **不足金の自動計算**
- **追加必要積立金の算出**
- **積立金推移グラフの表示**

## 使い方

1. ブラウザで `index.html` を開きます
2. 以下の情報を入力します：
   - 現在の積立金残高
   - 月々の積立金額（1戸あたり）
   - 総戸数
   - 年間小規模修繕費用
   - 大規模修繕予定費用
   - 大規模修繕までの期間（年）
3. 「計算する」ボタンをクリック
4. 結果が表示されます：
   - 期間内の積立金総額
   - 期間内の小規模修繕費用総額
   - 大規模修繕時の予想積立金残高
   - 不足金額（または余剰金額）
   - 不足分を補うための追加月額積立金
   - 積立金推移グラフ

## 計算式

- **期間内の積立金総額** = 月々の積立金 × 戸数 × 12ヶ月 × 期間年数
- **期間内の小規模修繕費用総額** = 年間小規模修繕費用 × 期間年数
- **大規模修繕時の予想積立金残高** = 現在の残高 + 期間内の積立金総額 - 期間内の小規模修繕費用総額
- **不足金** = 大規模修繕費用 - 予想積立金残高
- **追加月額積立金** = 不足金 ÷ (期間年数 × 12ヶ月)
